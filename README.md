# Curva de Aprendizaje - Científico de Datos / ML Engineer

Repositorio de estudio siguiendo la curva de aprendizaje propuesta por el equipo **Athena** (SETI S.A.S.) para el rol de Data Scientist / ML Engineer.

> Última actualización de la curva original: 22 de jul de 2026 — por Alex Vladimir Saya Gamboa

## Resumen

- **10 cursos** en total: 8 de Microsoft Learn + 2 de Udemy
- Distribución 80/20 por cantidad (mayoría Microsoft Learn)
- Certificación de referencia principal: **DP-100** (con soporte de DP-203, DP-600, DP-700, DP-3011)
- Plan sugerido: **20 semanas**, 2 semanas por curso

## Detalle por curso

### Curso 1 - Explore and Analyze Data with Python
- **Nivel:** Básico
- **Prioridad:** Obligatorio
- **Duración estimada:** 4-6 h de contenido | 8-12 h de práctica
- **Certificación relacionada:** DP-100 (base técnica)
- **Entregables prácticos:**
  - Notebook de exploración de datos
  - Perfilamiento de dataset
  - Visualizaciones con Matplotlib y Seaborn
- **URL:** https://learn.microsoft.com/training/modules/explore-analyze-data-with-python/

### Curso 2 - Introduction to Machine Learning Concepts
- **Nivel:** Básico - Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 5-8 h de contenido | 10-14 h de práctica
- **Certificación relacionada:** DP-100
- **Entregables prácticos:**
  - Mapa conceptual de tipos de ML (regresión, clasificación, clustering, deep learning)
  - Matriz de escenarios para seleccionar tipo de modelo
  - Notebook corto con ejemplos de problema supervisado y no supervisado
- **URL:** https://learn.microsoft.com/training/modules/fundamentals-machine-learning/

### Curso 3 - Train and evaluate regression models
- **Nivel:** Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 6-9 h de contenido | 12-18 h de práctica
- **Certificación relacionada:** DP-100
- **Entregables prácticos:**
  - Modelo de regresión entrenado con baseline y modelo mejorado
  - Evaluación con RMSE, MAE y R²
  - Notebook con ajuste de hiperparámetros y versión final
- **URL:** https://learn.microsoft.com/training/modules/train-evaluate-regression-models/

### Curso 4 - Train and evaluate classification models
- **Nivel:** Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 4-6 h de contenido | 8-12 h de práctica
- **Certificación relacionada:** DP-100
- **Entregables prácticos:**
  - Modelo de clasificación binaria y multiclase
  - Matriz de confusión y curva ROC/PR
  - Comparativo de métricas: precisión, recall, F1 y accuracy
- **URL:** https://learn.microsoft.com/training/modules/train-evaluate-classification-models/

### Curso 5 - Train and evaluate clustering models
- **Nivel:** Intermedio
- **Prioridad:** Recomendado
- **Duración estimada:** 3-5 h de contenido | 6-10 h de práctica
- **Certificación relacionada:** DP-100 (complementario)
- **Entregables prácticos:**
  - Segmentación con K-Means y método del codo
  - Evaluación de clusters con silhouette score
  - Perfil de segmentos con recomendaciones de negocio
- **URL:** https://learn.microsoft.com/training/modules/train-evaluate-cluster-models/

### Curso 6 - Create machine learning models
- **Nivel:** Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 8-12 h de contenido | 14-20 h de práctica
- **Certificación relacionada:** DP-203 / DP-600 (complementario)
- **Entregables prácticos:**
  - Mini portafolio con 3 modelos (regresión, clasificación y clustering)
  - Informe de comparación de desempeño entre modelos
  - Checklist de buenas prácticas para entrenamiento y evaluación
- **URL:** https://learn.microsoft.com/training/paths/create-machine-learn-models/

### Curso 7 - Python for Data Science and Machine Learning Bootcamp (Udemy)
- **Nivel:** Básico - Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 24-26 h de contenido | 50-70 h de práctica
- **Certificación relacionada:** Complementaria
- **Entregables prácticos:**
  - Proyecto EDA con Pandas, Matplotlib y Seaborn
  - Proyecto de clasificación con scikit-learn
  - Proyecto de regresión con validación cruzada
- **URL:** https://www.udemy.com/course/python-for-data-science-and-machine-learning-bootcamp/

### Curso 8 - Machine Learning A-Z: AI, Python and R (Udemy)
- **Nivel:** Intermedio
- **Prioridad:** Recomendado
- **Duración estimada:** 35-45 h de contenido | 70-100 h de práctica
- **Certificación relacionada:** Complementaria
- **Entregables prácticos:**
  - Implementación de modelos supervisados y no supervisados
  - Ejercicio de reducción de dimensionalidad (PCA/LDA)
  - Caso aplicado de selección y mejora de modelo
- **URL:** https://www.udemy.com/course/machinelearning/

### Curso 9 - Implement a Data Analytics Solution with Azure Databricks
- **Nivel:** Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 20-24 h de contenido | 35-50 h de práctica
- **Certificación relacionada:** DP-3011
- **Entregables prácticos:**
  - Notebook en Databricks con ingesta y transformación de datos usando Spark
  - Pipeline de procesamiento con Delta tables y validaciones de calidad de datos
  - Evidencia de orquestación de jobs y versionamiento de notebooks
- **URL:** https://learn.microsoft.com/training/courses/dp-3011

### Curso 10 - Ingest data with Microsoft Fabric
- **Nivel:** Intermedio
- **Prioridad:** Obligatorio
- **Duración estimada:** 6-10 h de contenido | 12-20 h de práctica
- **Certificación relacionada:** DP-600 / DP-700 (complementario)
- **Entregables prácticos:**
  - Pipeline de ingesta y orquestación usando capacidades de Data Factory en Microsoft Fabric
  - Flujo de transformación con Dataflows Gen2 para preparar datos analíticos
  - Evidencia de ejecución y monitoreo de pipelines en Fabric
- **URL:** https://learn.microsoft.com/training/paths/ingest-data-with-microsoft-fabric/
